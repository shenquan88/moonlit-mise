Moonlit Mise is an original, offline, playable-in-browser cooking game: read the orders, prep and chop ingredients, cook to order, plate up against the clock, and build combos and tips across four distinct dishes. Zero network, zero dependencies, no build step — Canvas 2D and vanilla JavaScript.

## Run it

```sh
node serve.ts
# then open http://127.0.0.1:8080 in a desktop browser
```
